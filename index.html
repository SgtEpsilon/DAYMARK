MODEL NOTES

The optimizer numerically samples a complete orbit and evaluates solar elevation for fixed surface coordinates. It supports ordinary rotation and synchronous rotation without requiring a separate planet type switch. The full search and the heatmap render run in a background worker, so the page stays responsive while an analysis is in progress.

The result is intended as a practical in-game coordinate finder. Game-specific orbital conventions may differ from a physical astronomy model, so treat the output as an approximation unless the game's coordinate/epoch conventions are known.

The game exposes no absolute orbital epoch, so the Time Window and Location Timeline panels treat "now" as t = 0 in the model rather than tying it to a real in-game date. Elapsed time within a window is accurate; its alignment to the planet's true real-time phase is not known.
